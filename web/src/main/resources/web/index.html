3 Card Blind

Each player picks three Vintage-legal cards. Every matchup is solved with perfect play on both sides, so the best deck wins.

These tournaments were solved on the author's computer. Watch any game, or ask for a deck or a matchup to be solved next.

Search settingsScoring

Games still going at the turn limit are draws, but the search goes on past it, up to 4 times the limit, in case a player wins slowly. Exact turns is slower, but exact for games decided near the limit. A game that runs out of time or nodes is scored as an unproven draw.

Save search trees keeps every game's searched tree to browse afterwards. It's for small tournaments (up to 8 entries): each game's tree can take a few MB, and cached games are solved again.

Scoring gives points for a win, a draw and a loss. It doesn't change any game, so it re-scores saved tournaments too. 2 / 1 / 0 is 3cardblind.com's scoring (a draw is half a win), and shows each deck's points as a percentage of the points it could have scored.
