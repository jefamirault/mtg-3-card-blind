3 Card Blind

Each player picks three Vintage-legal cards. Every matchup is solved with perfect play on both sides, so the best deck wins.

Search settings

Games still going at the turn limit are draws. Exact turns is slower, but exact for games decided near the limit. A game that runs out of time or nodes is scored as an unproven draw.

Save search trees keeps every game's searched tree to browse afterwards. It's for small tournaments (up to 8 entries): each game's tree can take a few MB, and cached games are solved again.
